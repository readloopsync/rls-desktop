# Finding your CrossPoint device's IP address

The **Mount in Finder** feature needs your device's local IP address (e.g.
`192.168.1.50`). In most cases Readloop fills this in for you automatically once
the device has connected to the app at least once (browsed the catalog or
synced). If the field is blank, here's how to read the IP off the device.

## On the device

1. Open **File Transfer › Join a Network**.
2. The screen shows a **QR code and the IP address** of your device on the
   current Wi-Fi network.
3. Type that IP into Readloop's **Mount in Finder** field.

> Make sure the device and your computer are on the **same Wi-Fi network** — the
> IP is only reachable within that network.

## Notes

- The IP can change when the device rejoins Wi-Fi (DHCP). If mounting stops
  working, re-check the address here.
- Readloop learns the IP automatically from the device's own connections, so
  after the first browse/sync you usually won't need this screen.
